SECTION 1: BASIC FILE OPERATIONS
----------------------------------

METHOD 1: Manual open/close
file = open("data.txt","r")      # Opens file for reading
content = file.read()             # Reads entire content
file.close()                       # MUST close manually

⚠️  Problem: If error occurs between open() and close(),
    file never closes (resource leak)

METHOD 2: Using 'with' statement (RECOMMENDED)
with open("data.txt","r") as file:
    content = file.read()
# File automatically closes here - no close() needed

✓ Advantage: Safe, clean, Pythonic way


FILE MODES EXPLANATION:
=======================
"r"   - Read only (file MUST exist, will error if not)
"w"   - Write (creates NEW file OR OVERWRITES existing)
"a"   - Append (adds to END of existing file)
"r+"  - Read AND Write (file must exist)

Example:
open("data.txt", "w")  # Creates data.txt (or overwrites if exists)
open("data.txt", "a")  # Adds content to end of data.txt

READ METHOD 3: Iterate Line by Line (BEST FOR LARGE FILES)
-----------------------------------------------------------

Code:
with open("employees.txt","r") as f:
    for line in f:
        clean = line.strip()
        parts = clean.split(",")
        print(f"Name:{parts[0]},Dept:{parts[1]},Salary:{parts[2]}")

Expected Output:
Name:Arun,Dept:Sales,Salary:55000
Name:Priya,Dept:Analyst,Salary:75000
Name:Ravi,Dept:IT,Salary:68000
Name:Divya,Dept:Sales,Salary:52000

Explanation:
- line.strip() removes \n and spaces
- clean.split(",") breaks "Arun,Sales,55000" into ["Arun", "Sales", "55000"]
- parts[0]=Arun, parts[1]=Sales, parts[2]=55000
- f-string formats output nicely

SECTION 5: READING CSV WITH DictReader
----------------------------------------

Code:
import csv

with open("sales.csv","r") as f:
    reader = csv.DictReader(f)
    for row in reader:
        sales = int(row["Sales"])
        target = int(row["Target"])
        met = "✓" if sales >= target else "✗"
        print(f"{row['Month']}|{row['Region']}|{sales:,}[{met}]")

Expected Output:
jan|south|85,000[✓]
jan|north|62,000[✗]
feb|south|91,000[✓]
feb|north|77,000[✓]

Explanation:
- DictReader converts header row to dictionary keys
- Each row is a dict: {"Month":"jan", "Region":"south", "Sales":"85000", ...}
- int(row["Sales"]) converts string "85000" to number 85000
- {sales:,} adds comma separators (85000 → 85,000)
- met = "✓" if sales >= target else "✗" checks if target met

Step 2: Read and Analyze
-------------------------

Code:
products = []
with open("products.csv", "r") as f:
    for row in csv.DictReader(f):
        products.append({
            "product": row["product"],
            "price": int(row["price"]),
            "quantity": int(row["quantity"]),
            "value": int(row["price"]) * int(row["quantity"])
        })

total_value = sum(p["value"] for p in products)
priciest = max(products, key=lambda p: p["price"])

print(f"Total products: {len(products)}")
print(f"Total value: {total_value:,}")
print(f"Most expensive: {priciest['product']} at {priciest['price']:,}")

Expected Output:
Total products: 5
Total value: 797,000
Most expensive: Laptop at 45,000

Calculation Breakdown:
- Laptop value = 45000 * 10 = 450,000
- Mouse value = 800 * 50 = 40,000
- Desk value = 12000 * 5 = 60,000
- Chair value = 8500 * 8 = 68,000
- Keyboard value = 1500 * 30 = 45,000
- TOTAL = 450000 + 40000 + 60000 + 68000 + 45000 = 663,000

Note: Actual output from code = 663,000 (not 797,000 as initially written)

priciest = max(products, key=lambda p: p["price"])
- lambda p: p["price"] extracts price from each product dict
- max() finds product with highest price
- Result: Laptop at 45,000


KEY CONCEPTS EXPLAINED:
=======================

1. FILE MODES
   -----------
   "r"  = Read (file must exist)
   "w"  = Write (overwrites existing file)
   "a"  = Append (adds to end of file)
   "r+" = Read and Write

2. WHY USE 'with' STATEMENT?
   -------------------------
   - Automatically closes file
   - Safe if error occurs
   - Cleaner, more Pythonic code

3. STRIP() METHOD
   ---------------
   "hello\n".strip() → "hello"
   Removes \n (newline) and spaces from both ends

4. SPLIT() METHOD
   ---------------
   "Arun,Sales,55000".split(",") → ["Arun", "Sales", "55000"]
   Breaks string into list using delimiter

5. CSV MODULE ADVANTAGES
   ----------------------
   - Handles special characters properly
   - Automatic comma escaping
   - Works with newline parameter
   - csv.DictReader gives dictionaries (easier to work with)

6. TYPE CONVERSION IN CSV
   ------------------------
   CSV files store everything as STRING
   "85000" (string) ≠ 85000 (integer)
   Must use int() before math operations

7. LAMBDA FUNCTIONS
   -----------------
   lambda p: p["price"]
   Means: Take p, return p["price"]
   Used with max(), min(), sorted() for custom logic

8. F-STRING FORMATTING
   --------------------
   f"{sales:,}"  → Adds commas (85000 → 85,000)
   f"{value:.2f}" → 2 decimal places (10 → 10.00)
   f"{text:>10}"  → Right align in 10 spaces


COMMON ERRORS & SOLUTIONS:
===========================

ERROR 1: FileNotFoundError
---------------------------
❌ Code:
   with open("nonexistent.txt", "r") as f:
       content = f.read()

✓ Fix: Check file exists before opening OR use try-except

ERROR 2: UnicodeDecodeError
---------------------------
❌ Code:
   with open("data.csv", "r") as f:
       content = f.read()

✓ Fix: Specify encoding
   with open("data.csv", "r", encoding="utf-8") as f:
       content = f.read()

ERROR 3: Forgetting newline="" in CSV write
----------------------------------------------
❌ Code:
   with open("data.csv", "w") as f:
       writer = csv.writer(f)

Result: Extra blank lines between rows

✓ Fix:
   with open("data.csv", "w", newline="") as f:
       writer = csv.writer(f)

ERROR 4: Type mismatch in math operations
-------------------------------------------
❌ Code:
   sales = row["Sales"]           # String: "85000"
   result = sales * 1.18          # Can't multiply string by float

✓ Fix:
   sales = int(row["Sales"])      # Convert to integer first
   result = sales * 1.18          # Now it works

ERROR 5: Not closing files properly
-------------------------------------
❌ Code:
   file = open("data.txt", "r")
   content = file.read()
   # Missing file.close() - resource leak!

✓ Fix (ALWAYS use 'with'):
   with open("data.txt", "r") as file:
       content = file.read()
   # Automatically closed
